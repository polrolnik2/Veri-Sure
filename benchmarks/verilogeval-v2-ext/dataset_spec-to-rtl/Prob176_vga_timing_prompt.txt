
I would like you to implement a module named TopModule with the following
interface.

 - input        clk
 - input        reset
 - output [9:0] x
 - output [9:0] y
 - output       hsync
 - output       vsync
 - output       active_video

Implement a VGA timing generator for 640x480 @ 60Hz using a pixel clock.

Counters:
 - `x` is the horizontal pixel counter and counts from 0 to 799 (800 total).
 - `y` is the vertical line counter and counts from 0 to 524 (525 total).
 - On each rising edge of `clk`, increment `x`.
 - When `x` reaches 799, on the next clock set `x` back to 0 and increment `y`.
 - When `y` reaches 524 and `x` reaches 799, the next clock starts a new frame:
   `x` becomes 0 and `y` becomes 0.

Visible region:
 - Visible pixels are `x < 640` and `y < 480`.
 - `active_video` must be 1 only inside the visible region, else 0.

Sync pulses (active-low):
 - Horizontal timing (total 800):
     visible 640, front porch 16, sync 96, back porch 48
   So HSYNC is LOW when 656 <= x <= 751, else HIGH.
 - Vertical timing (total 525):
     visible 480, front porch 10, sync 2, back porch 33
   So VSYNC is LOW when 490 <= y <= 491, else HIGH.

Reset:
 - `reset` is active-high synchronous.
 - On reset, set `x=0` and `y=0`.

All sequential logic is triggered on the positive edge of `clk`.
