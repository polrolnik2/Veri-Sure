
I would like you to implement a module named TopModule with the following
interface.

 - input  clk
 - input  reset
 - input  start
 - input  signed [15:0] angle
 - output signed [15:0] cos_out
 - output signed [15:0] sin_out
 - output done

Implement a CORDIC rotator in rotation mode to compute sine and cosine
using only add/subtract and shifts.

Angle format:
 - `angle` is signed degrees×256 (Q8.8). For example:
     0°   -> 0
     45°  -> 45*256  = 11520
     90°  -> 90*256  = 23040
 - Inputs are guaranteed to be in the range [-90°, +90°].

Output format:
 - `cos_out` and `sin_out` are signed fixed-point Q1.14 values.
   (Range approximately [-1.0, +1.0).)

Handshake / timing:
 - `reset` is active-high synchronous. On reset, clear internal state,
   set outputs to 0, and deassert `done`.
 - When idle, if `start` is 1 on a rising edge, latch `angle` and begin
   computation.
 - Perform exactly 12 CORDIC iterations (i = 0..11). The first iteration
   happens on the cycle after `start` is accepted.
 - After the 12th iteration, update `cos_out`/`sin_out` and assert `done`
   for exactly 1 clock cycle, then return to idle.
 - While busy, ignore `start` and ignore changes to `angle`.

CORDIC rotation equations (use arithmetic right shift `>>>`):
  Let z be the residual angle, and (x,y) be the vector.
  For iteration i:
    if z >= 0:
      x' = x - (y >>> i)
      y' = y + (x >>> i)
      z' = z - atan[i]
    else:
      x' = x + (y >>> i)
      y' = y - (x >>> i)
      z' = z + atan[i]

Use these atan constants in degrees×256:
  atan[0]=11520, atan[1]=6801, atan[2]=3593, atan[3]=1824,
  atan[4]=916,   atan[5]=458,  atan[6]=229,  atan[7]=115,
  atan[8]=57,    atan[9]=29,   atan[10]=14,  atan[11]=7

To compensate the CORDIC gain, initialize the vector to:
  x0 = 9949  (this is 0.607252... in Q1.14)
  y0 = 0

After 12 iterations, output:
  cos_out = x
  sin_out = y
