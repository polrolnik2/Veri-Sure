
I would like you to implement a module named TopModule with the following
interface.

 - input  clk
 - input  reset
 - input  [7:0] sample_in
 - output [7:0] avg_out

Implement an 8-sample moving-average filter (window size = 8) for an
unsigned 8-bit input stream.

On every rising edge of `clk` (when not in reset):
 - Shift `sample_in` into a shift-register holding the last 8 samples.
 - Maintain the running sum of the last 8 samples.
 - Update `avg_out` to the integer average of the window:

     avg_out = (sum_of_last_8_samples) / 8

Since the window size is 8, you should implement the division by 8 using
a right shift by 3.

`reset` is active-high synchronous. On reset, clear the window and sum to
0 and set `avg_out` to 0.
