
I would like you to implement a module named TopModule with the following
interface.

 - input        clk
 - input        reset
 - input        push
 - input        pop
 - input  [7:0] din
 - output [7:0] dout
 - output       full
 - output       empty

Implement a hardware stack (LIFO) with data width 8 and depth 16.

Reset / outputs:
 - `reset` is active-high synchronous.
 - On reset, clear the stack (occupancy becomes 0), set `dout` to 0,
   `empty=1`, and `full=0`.

Operation (on each rising edge of `clk`):
 - If `push=1` and the stack is not full, push `din` onto the stack.
 - If `pop=1` and the stack is not empty, pop the top element and output it
   on `dout`.
 - If `push` and `pop` are both asserted in the same cycle and the stack is
   not empty, treat it as a replace-top operation: output the popped top
   element on `dout` and then push `din` back onto the top (occupancy stays
   the same).
 - If `push=1` when `full=1` and `pop=0`, ignore the push.
 - If `pop=1` when `empty=1`, ignore the pop and keep `dout` unchanged.

`empty` indicates occupancy 0 and `full` indicates occupancy 16.

All sequential logic is triggered on the positive edge of `clk`.
