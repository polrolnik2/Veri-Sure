
I would like you to implement a module named TopModule with the following
interface.

 - input        clk
 - input        reset
 - input        in_valid
 - input  [7:0] in_data
 - output       in_ready
 - output       out_valid
 - output [7:0] out_data
 - input        out_ready

Implement a skid buffer (a small pipeline buffer) using the standard
valid/ready handshake.

Handshake:
 - An input transfer occurs when `in_valid=1` and `in_ready=1` on a rising
   edge of `clk`. The buffer must accept `in_data`.
 - An output transfer occurs when `out_valid=1` and `out_ready=1` on a rising
   edge of `clk`. The downstream consumes `out_data`.

Requirements:
 - The buffer must never lose or reorder data.
 - The buffer must apply backpressure by deasserting `in_ready` when it
   cannot accept new data.
 - Capacity is 2 entries (one currently presented on the output, plus one
   extra "skid" entry stored internally). This allows accepting one more
   input beat after the output side has stalled.

Reset:
 - `reset` is active-high synchronous.
 - On reset, clear the buffer (`out_valid=0`) and set `out_data` to 0. The
   buffer must be ready to accept new data (`in_ready=1`).

All sequential logic is triggered on the positive edge of `clk`.
