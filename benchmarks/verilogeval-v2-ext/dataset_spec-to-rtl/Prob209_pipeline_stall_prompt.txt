
I would like you to implement a module named TopModule with the following
interface.

 - input  clk
 - input  reset
 - input  stall
 - input  valid_in
 - input  [15:0] a
 - input  [15:0] b
 - output valid_out
 - output [16:0] sum

Implement a 2-stage pipelined adder with stall support and bubble
insertion.

Pipeline:
 - Stage 1 captures the input operands and a valid bit.
 - Stage 2 captures the computed sum and a valid bit.
 - The output `sum` and `valid_out` correspond to stage 2.

Bubble insertion:
 - When `stall` is 0, stage 1 must sample the inputs every cycle.
 - If `valid_in` is 0, stage 1 inserts a bubble (stage1_valid=0), which
   should propagate to stage 2 on the next cycle.

Stall:
 - When `stall` is 1, the entire pipeline must hold its state:
     * do not advance stage 1 or stage 2
     * do not sample new inputs
     * keep outputs stable

Reset:
 - `reset` is active-high synchronous.
 - On reset: clear both pipeline valid bits and set `sum` to 0.

All sequential logic is triggered on the positive edge of `clk`.
