
I would like you to implement a module named TopModule with the following
interface.

 - input  clk
 - input  reset
 - input  in_bit
 - input  [7:0] pattern
 - input  [3:0] pattern_len
 - output match

Implement a sliding-window serial pattern matcher with a *variable* pattern
length.

Maintain an 8-bit shift register holding the most recent input bits. On
each rising edge of `clk` (when not in reset):

  history <= {history[6:0], in_bit}

The newest received bit is stored in history[0]. The previous bit is in
history[1], etc.

`match` should be asserted for 1 clock cycle when the last `pattern_len`
bits equal the corresponding bits of `pattern`:

  match = (history_next[pattern_len-1:0] == pattern[pattern_len-1:0])

where history_next is the shifted value including the current `in_bit`.

Constraints:
 - Valid `pattern_len` values are 1..8. If `pattern_len` is 0 or >8,
   `match` must be 0.
 - `reset` is active-high synchronous. On reset, clear history to 0 and
   drive `match` low.
