## Why this is worth a run even though it is a ceiling

If iteration descends, the **prescription is golden-free**: run the loop to its
criterion's stopping point, re-select checks against the design it produced, and
loop again. Nothing in that needs a reference. This run measures whether the
descent exists at all before anything is built to exploit it — and if it does not,
that closes iteration as cheaply as it can be closed.
