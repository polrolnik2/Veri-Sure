# PRE-REGISTERED: can the second loop's fuel be AUTHORED soundly?

Fixed before any call. **Fully golden-free in selection and in the prompt** — the
audit runs last and selects nothing.

## Why this is the one route left in scope

The golden-free second loop is empty: of 255 corpus checks objecting to the design
loop 1 accepted, **zero pass the minority rule**, and the minimum convicts four of
nine against a threshold of two. Every closure argument this session has treated
the corpus as fixed.

**The goal does not.** It puts authoring in scope twice — *"regenerating oracles
up to new standards are fair game"* and *"take liberty with re-generating oracles
according to required standards."* So the question the closures have not asked is
whether a check with this objection can be **written** rather than **selected**.

## The admissibility problem, and how the design avoids it

The informative version of this experiment leaks. The 84 objections that powered
the chain were vetted **by the reference**, so telling an author *"preserve your
objection at TP-0047"* would put a reference-derived finding into an authoring
prompt — the thing `oracles_stage.py:66-73` forbids and this plan's control-leak
rule names.

**So the population is the 255, not the 84**, and both of its legs read only
spec-derived artifacts:

    OBJECTS   to the design loop 1 accepted -- a spec-derived design, not the reference
    OVER-STRICT  convicts all nine independently written implementations

The author is told exactly that, and nothing else about where it is right.

## The round

24 checks sampled deterministically across requirements from the 255. Each author
gets its own requirement's sentence, its current body, and one golden-free
objection: *"your check objects to this design here, and it also convicts nine of
nine independently written implementations of the same specification. Narrow it so
it stops convicting them and still objects here."*

## The bar

| outcome | reading |
|---|---|
| **>= 1 lands SOUND and still objects to loop 1's design** | **the golden-free second loop is unblocked.** Iteration becomes available without the reference, and the 62-testpoint gap is an authoring cost rather than a structural limit. Report the rate and the calls it took |
| **0 sound, but some pass the minority rule** | the rule can be satisfied by narrowing and soundness still is not. Record the rate beside the earlier narrowing rounds (15% then 4%) and build nothing |
| **0 pass the minority rule at all** | **narrowing cannot reach this population.** Going from nine-of-nine to two-of-nine while keeping an objection is past what this author can do, and the structural reading of the closure stands |

**VACUITY IS A LOSS AND IS COUNTED AS ONE.** The earlier narrowing rounds put 12
of 47 into checks that object to nothing; that is the knife-edge this population
sits on, and a check that stops convicting the nine by stopping objecting
entirely has not been narrowed, it has been deleted.

## Integrity pins

* **Leak check over every prompt before scoring**: zero lines of the reference's
  source, zero testpoint ids from the mask, zero equivalence verdicts, zero
  mentions of the reference.
* Population and objection are both golden-free; **the audit is computed last**.
* Integrity pass before scoring: all returned, all compile, no duplicate bodies
  across requirements, none returned unchanged.
* One round. The measured decay from the earlier narrowing rounds (15% -> 4%)
  applies, and a second round is not licensed by this one.
